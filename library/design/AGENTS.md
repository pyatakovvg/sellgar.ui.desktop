# @library/design

Общие компоненты представления витрины. Первый компонент — ProductCard из каталога.

- Компоненты получают подготовленные данные и управление через props.
- Не импортировать domain, pages, modules, widgets, layouts или application host. Загрузка, состояние приложения, команды и выбор маршрута остаются у потребителей.
- Использовать публичные primitives и tokens @sellgar/kit; kit не зависит от design.
- Публичные компоненты экспортировать именованно через src/index.ts. Внутренние props, стили и дети не экспортировать.
- Одна папка на компонент: имя.tsx, default.module.css, index.ts. Не сохранять копию перенесённого компонента у прежнего владельца.
- Пакет подключён к общим yarn lint/yarn format и проверке типов клиента. Для простого переноса UI проверять каталог и переход в карточку в браузере; новые stories/tests без отдельной задачи не нужны.

- Текст оформлять через Typography или готовые текстовые компоненты @sellgar/kit, например Badge. Не задавать font-size, line-height, font-weight и letter-spacing в локальном CSS. Для цены ProductCard использовать Typography size="body-s", для названия — size="caption-m". Персонализации показывать Badge, располагать линейно с переносом по ширине.
- ProductCard использует Image из кита с размером 192 × 192 и fit="contain" внутри стабильной области высотой 224 px. Область фото ограничивает переполнение. Бренд отдельной строкой над ценой, цена, название и бейдж находятся в одном блоке; описание не входит в плитку. Бренд не добавляется в название. Название ограничено двумя строками без резервирования пустой строки; бейдж следует сразу за ним с отступом по токену кита.
