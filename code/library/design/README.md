# @library/design

Переиспользуемые компоненты представления витрины поверх @sellgar/kit.

```tsx
import { ProductCard } from '@library/design';

<ProductCard
  href="/offers/offer-uuid"
  name="Футболка"
  variantName="Синяя"
  brandName="Бренд"
  imageUrl={imageUrl}
  imagePlaceholder="Ф"
  price="1 500 руб."
/>;
```

ProductCard показывает изображение или текстовую заглушку, бренд, название, персонализацию и цену. Цена и ссылка уже подготовлены потребителем; пакет не загружает товары и не обращается к корзине. Фото и название являются ссылками. Отдельной кнопки перехода и слота действий нет. Изображение использует Image из кита в области одинаковой высоты, поэтому его загрузка не сдвигает цену и текст.

Каталог в @page/home использует этот компонент через публичный фасад. Свойства, helpers и стили компонента остаются приватными.

Проверки из корня storefront: yarn typecheck, yarn lint. Визуальные изменения проверяются в работающем каталоге; отдельной сборки у source workspace нет.

Визуальный ориентир плитки — каталог DNS: самостоятельная зона фото без обрезки, компактная типографика, заголовки до двух строк, цена сразу под фото перед названием. Цвета и размеры берутся из кита Sellgar. Рейтинги, акции и доставка не отображаются без соответствующих данных.

Порядок блоков: фото → бренд → цена → название → бейдж персонализации. Бренд выводится отдельной строкой над ценой и не входит в обрезаемое название. Описание не входит в компактную плитку. Наличие не вычисляется и не маркируется карточкой: отбор товаров принадлежит client BFF.

При наведении нейтральная рамка появляется за 200 мс по токену кита, без изменения размеров карточки. Цвет названия остаётся неизменным; при reduced motion переход отключён.

Фотография использует `Image fit="contain"`: вертикальные и горизонтальные изображения целиком помещаются в 192 × 192, а область фото ограничивает переполнение. Изображение не перекрывает цену и название.

Клавиатурный фокус использует семантический токен кита `--border-action-focus-info`. Доступные названия ссылок содержат название товара, бренд и персонализацию; видимый текст названия сохраняется.

Цена использует `Typography size="body-s"`, название — `Typography size="caption-m"` из кита. Название ограничено двумя строками без резервирования пустой строки. Персонализация оформлена `Badge size="sm" color="blue"`; группа бейджей располагается линейно с переносом по ширине сразу под названием. Цена, название и бейдж объединены одним контейнером с шагом 8 px по токену кита. Локальный CSS не задаёт шрифты. Название не меняет цвет при hover.
