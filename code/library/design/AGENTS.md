# @library/design

Общие компоненты представления витрины: ProductCard, Image и PageLoader.

- Компоненты получают подготовленные данные и управление через props. ProductCard использует Link из @sellgar/app/next для общей индикации браузерных переходов; загрузка и выбор href остаются у потребителя.
- Не импортировать domain, pages, modules, widgets, layouts или application host. Загрузка, состояние приложения, команды и выбор маршрута остаются у потребителей.
- Использовать публичные primitives и tokens @sellgar/kit; kit не зависит от design.
- PageLoader использует Spinner и Typography из кита и CSS-токены; компонент не зависит от runtime приложения или роутера. Application host задаёт его через app.components({ fallback: React.createElement(PageLoader) }); показом при подготовке страниц управляет Next-адаптер фреймворка.
- Публичные компоненты экспортировать именованно через src/index.ts. Внутренние props, стили и дети не экспортировать.
- Одна папка на компонент: имя.tsx, default.module.css, index.ts. Не сохранять копию перенесённого компонента у прежнего владельца.
- Пакет подключён к общим yarn lint/yarn format и проверке типов клиента. Для простого переноса UI проверять каталог и переход в карточку в браузере; новые stories/tests без отдельной задачи не нужны.

- Текст оформлять через Typography или готовые текстовые компоненты @sellgar/kit, например Badge. Не задавать font-size, line-height, font-weight и letter-spacing в локальном CSS. Для цены ProductCard использовать Typography size="body-s", для названия — size="caption-m". Персонализации показывать Badge, располагать линейно с переносом по ширине.
- ProductCard использует Image из design внутри области размером 192 × 192, помещённой в стабильную область фото высотой 224. Размеры задаются токенами кита. Область фото ограничивает переполнение. Бренд отдельной строкой над ценой, цена, название и бейдж находятся в одном блоке; описание не входит в плитку. Бренд не добавляется в название. Название ограничено двумя строками без резервирования пустой строки; бейдж следует сразу за ним с отступом по токену кита.
- Image — клиентская обёртка next/image с fill, обязательными alt и sizes, fit="contain" по умолчанию. Родитель задаёт стабильную ширину и высоту через CSS. sizes описывает размер ресурса для браузера, а не CSS-размер блока. Карточки, галерея, изображения свойств и мини-корзина используют этот компонент.
- Загрузка обозначается синим Loader4LineIcon через Animate.Spin из кита; ошибка — ImageLineIcon. Изображение не скрывается во время загрузки. При монтировании проверяется complete/naturalWidth для кешированных файлов, при смене src создаётся новый узел next/image; onLoad/onError передаются потребителю. Общего кеша состояния загрузки в React нет.
- Next Image Optimizer настроен в clients/desktop/next.config.ts: только HTTPS dev.sellgar.ru/api/client/v1/files/* без query и редиректов. Доступ к приватным IP разрешён для gateway локальной K3s VM. При подключении другого публичного gateway обновлять явный remotePatterns; не разрешать произвольные hosts.
